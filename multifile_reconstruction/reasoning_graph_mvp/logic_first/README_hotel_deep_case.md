# 酒店定价试点复核

从 `ICM2027/` 运行以下命令生成并验证一个案例。

```bash
python -m multifile_reconstruction.reasoning_graph_mvp.logic_first.hotel_deep_case
```

默认产物在 `business_artifacts/hotel_deep_case/`。`index.html` 链接公开材料、参考文件和验证结果。构建复用已有酒店公式提案、验证器与原生 Office 渲染。指标定义引用前次核验的业务定义，试点政策和基础账本是为这个案例设定的合成数据。构建、参考评分和捷径检查由程序执行，Agent 调用为零。

## 更正及预期结果

Willowbank 的已售间夜数由 6,000 更正为 8,000。Word 的政策按入住率低于 75% 选出价格对照组，房价线等于对照组房价的等权平均再加 5 元。全体酒店按入住率至少 75% 且平均房价不低于房价线判断资格，等于门槛时入选。

对照组平均房价由 140 元变为 120 元，房价线由 145 元变为 125 元。Harborstone 始终入选，Willowbank 和 Silverbrook 在更正后入选。后者的基础数据未变化，资格因对照组门槛下降而变化。Willowbank 的 RevPAR 始终为 108 元。这个不变性在保留的派生路径上可以验证，当前材料将该数值保留在构建端。Excel 和 PPT 中 Harborstone 的对应状态为相关但应保留的原生对象。

## 深度和文件必要性

入选名单按登记的语义算子有 5 层最短路径，家数和入选平均房价各为 6 层。把溢价从对照组均值一侧移到每家酒店的房价一侧，可以把名单计算从 6 层缩到 5 层。`shortcuts.json` 另以公开的旧名单和旧均值核验增量重算。把多个语义操作合并视作一次表格函数调用，记录为另一种计量口径。部分组合可缩到 3 次函数调用。自然语言或任意程序的全部可能路径超出本次审计范围。

Excel 提供可售与已售间夜数，PPT 提供客房收入，Word 提供政策和参数。所有 8 个文件子集均按实际文件读取值核验。每个不充分子集都有同公开更正、同可见旧结果、但新业务答案不同的反例。完整包中已核准的来源记录采用更正后版本，待修改的复核报表采用先前发布版本。

## 节点真值与文件边界

`private/propagation.json` 按稳定 ID 汇集每个节点的前后 GT、变化状态、经过的规则、可用替代路径、每家酒店的变化以及实际原生位置。未物化的节点仍有记录，并显式标为构建端内部。`propagation.md` 提供简明阅读版。

每个文件位置都记录证据 ID、数据版本、初始与参考文件读取值以及处理动作。动作包括编辑、公式随输入重算、原样保留。PPT 数据表、缓存和内嵌工作簿分别绑定。Excel COUNTIF 保留公式并重算计数。Oracle 核验参考文件，同时拒绝原样提交、漏改 Word、替换公式、仅改图表缓存以及误改仍然入选酒店的资格标记。
