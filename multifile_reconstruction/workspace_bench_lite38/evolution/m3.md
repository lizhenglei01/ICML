# Add reusable re-employment history

Extend the supplied workbook so the same employee can leave and later return with the same employee ID. The original active and archived employee records are the initial employment records. Keep their contents intact. Add a visible `EmploymentPeriods` input sheet with columns `Employee ID`, `Employment Period ID`, `Hire Date`, `Separation Date`, and `Starting Department`, in that order, starting at row 2. This table contains subsequent periods only. Support at least 50 additional periods. The period ID is unique. Dates are Excel dates and a blank separation date means the employment is open. Tests use valid, ordered, nonoverlapping periods and preserve the starting records. A person's periods may have a gap. Some people originate in `SeparatedEmployeeArchive` and retain the stable IDs already assigned there.

Use the workbook's existing headcount convention: include a person only after their hire date and before their separation date. Apply permanent transfers and temporary assignments to the period in which the transfer effective date or assignment start date falls. Never carry a transfer or assignment from an earlier period into a later one. When a later period starts, start from its new starting department. Apply the former permanent transfer and temporary assignment precedence within each period. Separate employees with the same displayed name by ID when an ID is supplied.

Update the existing employee department lookup, current department summary, monthly opening and ending headcounts and annual opening and ending headcounts. Keep the existing report selectors and annual named ranges. Add two workbook-level names `EmploymentEmployeeID` and `EmploymentReportDate`, each referring to a visible single input cell. A nonblank ID selects that person, including an archived employee. If the ID is blank, use the existing name selector. A blank date uses today. The existing lookup department output must be empty when the person has no active employment at the requested date.

Include each subsequent hire and separation in the corresponding monthly activity rows already used by the workbook. Each is attributed to the starting department of that period, with the event counted on its recorded date. Do not count a permanent transfer or temporary assignment as a hire or separation. Show rehires separately as a subset of hires, and show annual activity totals for the selected year. Expose four visible seven-cell ranges named `MonthlyRehireCounts`, `AnnualHireCounts`, `AnnualSeparationCounts`, and `AnnualRehireCounts`, in the same department order as `MonthlyChangeQuery!C5:I5`. Include both initial and subsequent periods in annual hire and separation totals. Keep original monthly activity results in the absence of additional periods.

Preserve the existing permanent transfer and temporary assignment interfaces, the populated permanent transfer records, original workforce fields, HR cost totals, and contract reminders. Leave the new input table and two optional employee query inputs blank in the delivered workbook. Inserting new valid rows should update results on recalculation. Return the upgraded XLSX.
