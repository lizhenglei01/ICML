# Lite 38 Qwen4-Max M2 日期口径诊断

M2 继承 Qwen4‑Max 实际提交的 M1 工作簿。冻结评分为 **66/133**，借调重点检查 **4/12**。同一冻结测试在 M2 前后发现四条旧月末人数检查从通过变为失败。[运行清单](../lite38_model_comparison_qwen4/manifest.json)

在相同用例中，LibreOffice 将原工作簿月报的两个日期选择公式算成 `#VALUE!`。M1 的月末公式直接统计当前在职列，部分旧测试仍能得到期望值。M2 新的历史月末公式读取报告结束日，因而也返回 `#VALUE!`。

诊断只在重算副本的 `MonthlyChangeQuery!H4` 和 `J4` 写入该测试实际使用的月初和月末日期。正式提交、题面、计算规则、测试输入和 GT 的业务含义保持一致。按此方法重算 M2 的起点和提交后，借调重点检查 **12/12**，总计 **118/133**，四条候选回归均消失。剩余差异集中在年度报告和少数旧离职报表检查。冻结原分和复核分单独保存。[复核清单](manifest.json)
